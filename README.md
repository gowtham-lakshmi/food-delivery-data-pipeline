# Food Delivery Data Pipeline

A complete data engineering project — cleaning raw food delivery data and visualizing it in Power BI.

## What I did
- Cleaned raw data (missing values, duplicates, inconsistent text) using Python (pandas) in VS Code
- Uploaded cleaned data to AWS S3
- Built an interactive dashboard in Power BI with KPI cards, charts, and a detailed order table

## Tools used
- Python (pandas)
- AWS S3
- Power BI
- GitHub

## Files
- `raw_food_delivery_data.csv` — original raw data
- `clean_data.py` — data cleaning script
- `cleaned_food_delivery_data.csv` — cleaned data
- `Food_Delivery_Dashboard.pbix` — Power BI dashboard
