Food Delivery Data Pipeline

A complete Data Engineering project for cleaning, storing, transforming, and visualizing food delivery data using Python, AWS S3, Snowflake, Github and Power BI.

What I did
* Cleaned raw food delivery data using Python (Pandas) in VS Code
* Handled missing values, duplicates, and inconsistent text
* Uploaded cleaned data to AWS S3
* Loaded and managed data in Snowflake
* Created tables and performed SQL-based data analysis in Snowflake
* Built an interactive Power BI dashboard with KPI cards, charts, and a detailed order table
* Maintained the project code and files using GitHub
